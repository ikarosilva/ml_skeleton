v2 Iteration Workflow


# 1. Listen & Rate songs from the playlists
#    - Open recommender_help.xspf (high uncertainty) or recommender_best.xspf
#    - Rate in Clementine
#    - Update db with "~/git/clementine$ python main.py backup"

# 2. Retrain classifier (picks up new ratings automatically)
./run_music_pipeline.sh classifier --final-training -N 3

# 3. Review A/B test results (printed after training)
#    - New model vs prod model on held-out new ratings
#    - Shows p-value for statistical significance

# 4. If improved, promote to production
./run_music_pipeline.sh promote-to-prod

# 5. Generate new recommendations with some predicted dislikes
./run_music_pipeline.sh recommend --prod --low-rating-ratio 0.1

# 6. Repeat from step 1
Key Files Updated Each Cycle:

checkpoints/training_manifest.json - tracks train/val split
checkpoints/classifier_best.pt - new model
prod/ - production models (after promote)
If encoder needs update (e.g., new architecture):


./run_music_pipeline.sh encoder --final-training --encoder-version v2
./run_music_pipeline.sh classifier --final-training  # Must retrain



# 1. Listen & Rate songs (same as before)

# 1b. (Optional) Retrain encoder if you want to improve embeddings
./run_music_pipeline.sh encoder --final-training --encoder-version v2
# This automatically regenerates embeddings for all songs

# 1c. (Optional) Run encoder HPO if experimenting with architecture
./run_music_pipeline.sh hpo-encoder
./run_music_pipeline.sh encoder --final-training --best-params checkpoints/best_encoder_params.json

# 2. Retrain classifier (required after encoder change)
./run_music_pipeline.sh classifier --final-training --N 3

# 3-6. Same as before...
When to update encoder:

New ratings won't improve encoder (it's self-supervised on audio, not ratings)
Update encoder if: changing architecture, adding more songs to collection, or tweaking augmentations
When to skip encoder:

Just iterating on ratings → only retrain classifier
Encoder is already good → classifier updates are fast (~2 min vs hours)
Quick reference:

Change	Encoder	Embeddings	Classifier
New ratings only	Skip	Keep	Retrain
New encoder params	Retrain	Regenerated	Retrain
New songs added	Retrain	Regenerated	Retrain
